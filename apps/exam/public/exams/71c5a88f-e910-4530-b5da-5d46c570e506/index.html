指令用法提示 ｜ execute 指令用法：在基岩版中， execute as <目标> run <指令> 可将执行者切换为目标实体并执行后续指令。
例如： execute as @a run say 你好 ，表示让所有玩家执行"say 你好"。
JSON 文本用法提示 ｜ 基岩版 tellraw 命令使用 rawtext 格式，基本结构为： {"rawtext":[{"text":"要显示的文字"}]} 。若需显
示玩家名称，可使用 {"selector":"@a"} 。例如： tellraw@a {"rawtext":[{"text":"恭喜"},{"selector":"@a"},{"text":"获得称号！"}]} ，
将向所有玩家显示"恭喜[玩家名]获得称号！"。
系统需求:
检测玩家首次获得钻石，赋予"矿工"标签
向全服广播该玩家获得称号
检测玩家背包中铁锭数量达到 64 个，赋予"铁匠"标签
给予达标玩家铁镐作为奖励
（1）下列关于基岩版指令语法的说法，正确的是（3 分）
A. execute 命令中的 as 子命令可以将执行者切换为指定实体，但无法改变执行位置

C. tag 命令在基岩版中可以直接对目标选择器使用 add / remove 子命令，无需 execute 嵌套
